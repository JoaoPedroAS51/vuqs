# disableDebug <Badge type="tip" text="@vuqs/core/debug" />

Disables the official console projection.

## Usage

```ts
import { disableDebug } from '@vuqs/core/debug'

disableDebug()
```

## Type

```ts
function disableDebug(): void
```

## Return value

`void`. Independently attached reporters and persisted browser configuration are unaffected.
